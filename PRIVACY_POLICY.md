## 1. Our Privacy Commitment
Ocal Code is engineered from the ground up as a **Privacy-First, Offline-First Developer Environment**. We believe developer code, environment variables, API keys, and workspace assets are private property that must never leave your machine without your explicit direction.

## 2. Information We Do NOT Collect
- **Zero Source Code Telemetry**: We do not upload, scan, analyze, or send your code or files to cloud servers.
- **Zero Keylogging or Analytics**: Keystrokes, terminal commands, and editor contents remain 100% in local memory and local disk.
- **Zero Advertising Trackers**: No third-party ad networks or analytics beacons are embedded in Ocal Code.

## 3. Network Communications
The only network communications initiated by Ocal Code are:
1. **GitHub Update Checks**: When manually or automatically checking for updates, Ocal Code contacts `https://api.github.com/repos/neelkanth-patel26/Ocal-Code/releases/latest` to check version tags.
2. **Local Live Server**: The integrated web server binds to `127.0.0.1:5500` (loopback only) on your machine for web preview.
3. **User-Initiated Tools**: Commands run in the terminal (such as `npm install` or `git push`) communicate directly with their respective services as specified by the user.

## 4. Local Storage
User settings (such as chosen color theme, compiler configuration, and editor tab state) are stored strictly on your local machine using standard `localStorage` and OS application data directories.
